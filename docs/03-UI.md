# Weft — Surface design (part of Gate 1)

**Status:** drafted 2026-09-05, awaiting owner approval alongside [01-DESIGN.md](01-DESIGN.md).
**Prototype:** [prototype/weft.html](prototype/weft.html) — a static, clickable, high-fidelity page.
**Rule inherited from Zeno:** if this prototype is approved, the build **ports its markup and CSS**

## 1. Design intent in one paragraph

Weft looks like a **writing instrument with a visible nervous system**. The page is a calm,
opaque, paper-like editor; around it floats a thin layer of glass chrome — a top bar, a floating
format bar, a status pill, a command palette — that lenses the ambient colour behind it. The one
thing every other editor hides, the sync state, is Weft's most legible object: a pill that
always says *where* your work is (memory, this device, server) and *who* is here. The demo panels
(Sync Inspector, time-travel) are first-class, not debug afterthoughts, because convergence is
the product.

## 2. Design language: "Loom glass"

### 2.1 Layering (Apple's rule, adopted)

| Layer | Material | Examples | Never |
|-------|----------|----------|-------|
| L0 Ground | ambient gradient field (slow drift, 3 blurred radial blobs in the accent hues) | body background | — |
| L1 Content | **opaque** paper surface | editor page, history panel, Sync Inspector body | blur |
| L2 Navigation | **glass** (`backdrop-filter`) | top bar, floating format bar, status pill, ⌘K dialog, presence popover | glass inside glass; text directly on raw glass |

Glass count on screen at once: **≤ 3** (top bar, status pill, one transient). Every text label
inside a glass pane sits on an inner fill of ≥ 60% alpha so contrast stays ≥ 4.5:1 over the
worst-case ground.

### 2.2 Tokens (OKLCH, dark-first, light mirrored)

```css

  --bg:        oklch(15% 0.012 250);   /* dark navy-grey, never pure black */
  --paper:     oklch(20% 0.010 250);   /* editor page */
  --raised:    oklch(25% 0.010 250);   /* panels */
  --line:      oklch(32% 0.012 250);
  --ink:       oklch(94% 0.008 90);    /* warm off-white text */
  --ink-2:     oklch(72% 0.010 250);
  --ink-3:     oklch(56% 0.012 250);

  --accent:    oklch(78% 0.14 200);    /* teal */

  /* glass */
  --gl-fill:   oklch(22% 0.012 250 / .55);
  --gl-edge:   oklch(100% 0 0 / .12);
  --gl-spec:   oklch(100% 0 0 / .32);

  --p0: oklch(75% 0.16 20);  --p1: oklch(75% 0.16 65);  --p2: oklch(75% 0.16 110); --p3: oklch(75% 0.16 155);

  /* radius, motion */
  --r-1: 8px; --r-2: 12px; --r-3: 18px; --r-pill: 999px;

}
:root[data-theme="light"] { --bg: oklch(97% 0.006 90); --paper: oklch(99.5% 0.003 90); --raised: oklch(96% 0.006 90);
  --line: oklch(88% 0.008 90); --ink: oklch(20% 0.01 250); --ink-2: oklch(42% 0.01 250); --ink-3: oklch(58% 0.01 250);
  --gl-fill: oklch(100% 0 0 / .55); --gl-edge: oklch(20% 0.01 250 / .10); --gl-spec: oklch(100% 0 0 / .9); }
@media (prefers-color-scheme: light) { :root:not([data-theme="dark"]) { /* same as light block */ } }
@supports not (backdrop-filter: blur(1px)) { .glass { background: var(--raised) } }
@media (prefers-reduced-transparency: reduce) { .glass { backdrop-filter: none; background: var(--raised) } }

```

A manual **Reduce transparency** and **Theme** control lives in ⌘K, because
`prefers-reduced-transparency` is not Baseline yet.

### 2.3 The glass recipe (the only one; reused, never re-invented)

```css
.glass { background: var(--gl-fill); backdrop-filter: var(--gl-blur); -webkit-backdrop-filter: var(--gl-blur);
  border: 1px solid var(--gl-edge); box-shadow: var(--gl-shadow); border-radius: var(--r-3); isolation: isolate; }
.glass::before { /* specular seam */ content:""; position:absolute; inset:0 0 auto; height:1px;
  background: linear-gradient(90deg, transparent, var(--gl-spec) 25%, var(--gl-spec) 75%, transparent); opacity:.6; }
```

Optional Chromium-only refraction (`feDisplacementMap` on an SDF map) is allowed on the ⌘K
dialog **only**, declared after the plain recipe so other engines fall back.

## 3. Information architecture

One screen. No routes other than `/d/<docId>`; `/` redirects to a new id.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ L2 top bar (glass): ⌘ Weft · doc title (first heading) · ⋯ · [avatars]   │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   L1 editor page (opaque, 68ch max width, centred)      L1 side rail    │
│   ProseMirror; remote carets; selections               (opaque, closed  │
│                                                          by default):    │
│   [L2 floating format bar appears over a selection]      · Sync         │
│                                                            Inspector    │
│                                                          · History /    │
│                                                            time-travel  │
│                                                                          │
│ L2 status pill (glass, bottom-left)   L2 ⌘K dialog (glass, transient)    │
└──────────────────────────────────────────────────────────────────────────┘
```

Inline strip **above the editor** (opaque, not a toast) for reconnect and divergence notices.

## 4. Components and their states

### 4.1 Status pill — the honest object

Drawn **only** from the session state machine (LLD §4) and persisted facts. Colour + word + count.

| Session state | Pill | Colour | Meaning shown on hover/click (popover) |
|---------------|------|--------|-----------------------------------------|
| `live`, nothing pending | `● Saved` | ok | "Every change is on the server. Last ack 2 s ago." |
| `live`, N unacked | `● Syncing · N` | sync | "N changes are on this device and in flight." |
| `syncing` (catch-up) | `● Catching up · N in, M out` | sync | counts from the SV diff |
| `connecting` | `● Connecting…` | warn | attempt number, next retry in Ns |
| `degraded` (backoff) | `● Reconnecting in 8s · N on this device` | warn | last error text + **Retry now** button |
| `offline` (user toggle or `navigator.onLine` false) | `● Offline · N changes on this device` | warn | "Saved on this device. Will sync when back online." |
| divergence tripwire (I5 hash mismatch) | `● Diverged — report` | bad | shows both hashes; never hidden |
| durable storage (working IndexedDB) | no suffix — persistence is requested **silently** on load (`navigator.storage.persist()`, answer discarded) | — | on Chrome the call never prompts and returns false on localhost, so a warning drawn from it was alarmist and a dead end; it was removed (S4 UX change) |
| IndexedDB could not be opened (S4 extension, LLD E45) | suffix `· not persisted on this device` | warn | "IndexedDB could not be opened, so changes live in this tab's memory only and are gone when it closes." — the one real, surfaced storage warning |
| `failed` — fatal server code (S3 E19) / the store refused a write (S4 E43) | `● Can't connect · CODE` / `● Can't save · STORE_FAILED` | bad | the reason; the error card of §4.9 below the editor with **Retry** / **Start fresh (keeps a copy)** |

**Never** "Saving…" without a place. **Never** the same rendering for "no peers" and "no server".

Popover text per state, as built (S4): live `Every change is on the server. Last ack N s ago.` ·
live with N unacked `N changes are on this device and in flight.` · syncing `N ops coming in, M going
out, computed from the state-vector diff.` · connecting `Attempt N. The server has 5 s to answer
before the next try.` · degraded `Last error: …` + **Retry now** · offline as in the table · failed
the reason + `Nothing is sent; every change stays on this device.` The storage caveat is appended
when the suffix shows.

### 4.2 Presence (avatar stack, top-right)

- Connected, alone: a single self avatar + label **`Only you`**.
- Connected with peers: self + up to 4 peer avatars, `+N` overflow. Faded avatar = idle > 60 s.
- Disconnected: peers collapse to a **ghost avatar with a slash** and label `Peers unknown` — the
  server is the only source of presence and it is unreachable. This is the "no collaborators ≠
  broken" rule made visual.
- Click an avatar → **follow** (Zed): viewport tracks their caret; the editor gets a 2 px frame in
  their colour; any local keystroke or scroll exits follow.

### 4.3 Remote carets and selections

- Caret: 2 px bar in the peer's hue; name flag above (`border-radius: 3px 3px 3px 0`, 12 px, 600
  weight, ink on hue) visible for 1.5 s after movement and on hover; caret fades to 40% after 30 s
  idle; removed when awareness times out (30 s).
- Selection: peer hue at 25% alpha.
- Carets are anchored to item ids (LLD `ItemAnchor`), so they stay attached to the right
  character during concurrent edits — a visible correctness feature, and the demo points at it.

### 4.4 Floating format bar (glass, transient)

Appears over a non-empty selection: **B** *I* `</>` 🔗 · ¶ H1 H2 H3 • ❝. Keyboard: Ctrl+B/I/E/K,
Ctrl+Alt+1/2/3. Disabled items are dimmed, not hidden.

### 4.5 Sync Inspector (side rail, opaque) — the demo's proof panel

- One **lane per replica** (this device first): replica id, colour, state vector as chips
  `a:412 b:97 c:0`, and the last 12 ops as small chips `7@b` in the author's hue (Peritext notation).
- Footer line, computed from real messages: `A ≡ B ✓ converged` (ok) · `A ≠ B · 2 ops in flight`
  (sync) · `A ≠ B · hashes differ` (bad, tripwire).
- Controls: **Simulate offline** (closes the socket for real), **Drop next N messages**,
  **Delay 2 s** — chaos controls the demo and tests share.

### 4.6 History / time-travel (side rail, opaque)

A slider over the op log with a numeric position; the page re-renders `fold(apply, ∅, ops[0..n])`.
Per-author colouring of the visible text as an optional overlay (`Show authors`). Named versions
and restore are **not** in v1 (design §6).

### 4.7 Inline notices (opaque strip above the editor)

- Reconnect: `Back online — 12 offline edits merged.` with **Show in Inspector**.
- Divergence: `Replicas disagree (hash mismatch). Nothing was lost; this is a bug and has been
  logged locally.` with **Copy report**. Persistent until dismissed.
- Storage: there is **no** proactive storage notice (S4 UX change). Durable storage is requested
  silently on load (`navigator.storage.persist()`, answer discarded) — on Chrome it never prompts
  and returns false on localhost, so the old "This browser may evict Weft's offline storage." popup
  with **Ask to persist** was alarmist and a dead end and was removed. The only surfaced storage
  warning is the pill's `· not persisted on this device` suffix (§4.1) when the store fell back to
  this tab's memory.

### 4.8 ⌘K palette (glass)

Groups: **Document** (Rename via heading, New document, Theme, Reduce transparency) ·
**Collaboration** (Set my name, Follow…) · **History** (Time-travel, Show authors) ·
**Debug** (Simulate offline, Drop next N, Toggle Inspector, Copy state vector). Real dialog:
focus trap, Esc closes, focus returns.

### 4.9 Empty, loading, error — three different things

- Loading: 3 skeleton lines on the paper, nothing else.
- Empty doc: a single ghost line `Start writing, or press ⌘K` — never a skeleton.
- Load error (IndexedDB unavailable / corrupt): opaque card on the paper with the actual error and
  two actions **Retry** / **Start fresh (keeps a copy)**. Never silently blank.

## 5. Motion

`--t-fast` for hover and caret flags; `--t-base` for pill state changes and the inline strip;
`--t-slow` for the side rail. Remote carets glide on `--ease` over `--t-base`. Ground drift is a
46 s loop. All of it is removed under reduced motion; nothing depends on animation to be
understood.

## 6. Accessibility floor

Focus ring 2 px accent, offset 2 px, never obscured by the glass bar (WCAG 2.2 Focus Not
Obscured — the bar has `scroll-padding-top`). All status conveyed by **word + colour + icon**.
Pill and inline strips are `role="status"` (`aria-live="polite"`); divergence is
`role="alert"`. Presence avatars have names; carets are `aria-hidden` (their information is
duplicated in the presence list).

## 7. What the prototype must contain (for the build to port)

Static HTML + CSS + vanilla JS; no framework; also published as an interactive artifact, so the
file carries no `<html>/<head>/<body>` wrapper of its own. A **Flow map** indexes every screen and
every flow; each flow is a stepper with Prev/Next.

**Screens:** Live editor · Offline · Reconnected · Diverged · Alone · Loading · Empty · Error card
· ⌘K palette · Sync Inspector · History/time-travel · Presence popover + Follow · Pill popover ·
Floating format bar · Light theme · Reduced transparency.

**Flows:** F1 open and type together · F2 go offline and type at the same spot · F3 reconnect and
converge · F4 kill the tab and reopen (design §4.3) · F5 divergence tripwire · F6 follow a peer ·
F7 format text · F8 time-travel · F9 storage may be evicted · F10 protocol version mismatch (fatal
error card, work stays safe on device) · F11 ⌘K · F12 light theme and reduced transparency.

Real copy from §4, real tokens from §2. No lorem ipsum — the sample document is the interleaving
example from the design (`Hi there!` vs `Hi!`). Counts in the prototype are illustrative and
internally consistent (31 offline edits everywhere); they are not measurements.
